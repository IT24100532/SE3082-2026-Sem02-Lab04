Exercise 2: S = sum_{i=1..N} [ i - i^2 + sqrt(2 x (i + 1)) ], N = 10,000,000, with mutexes
Run on: Debian Linux container (Docker), gcc 14.2, 8 logical cpus. Build: make   Run: make run

sum_critical.c and sum_atomic.c protect "S += term" with critical / atomic.

The answer is now correct for every thread count (the racy Lab 03 version gave values
like -1.0e+20). Like Exercise 1, it is slower than serial (10 ms): every addition waits
for the lock, so the threads queue up one by one. atomic is cheaper than critical.
